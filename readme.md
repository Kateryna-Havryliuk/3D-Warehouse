## 🎯 Опис проєкту

**3D Smart Warehouse** — інтерактивна система візуалізації та управління складськими запасами для приватного підприємства. Система дозволяє комірникам у режимі реального часу знаходити розташування товарів у тривимірному просторі складу площею **738 м²** (41×18 м).

### Проблема, яку вирішує проєкт

|               Проблема                |              Вплив                |           Рішення в проєкті         |
|---------------------------------------|-----------------------------------|-------------------------------------|
| Витрати часу на пошук товарів         | Затримки у відвантаженні          | 3D-навігація з маршрутами           |
| Відсутність візуального представлення | Помилки у розміщенні              | Інтерактивна модель всіх стелажів   |
| Складність інвентаризації             | Неточності обліку                 | Цифровий облік з історією операцій  |
| Робота без комп'ютера                 | Неможливість оперативного доступу | PWA-додаток для смартфонів          |

### Основні характеристики складу

- **Площа:** 738 м² (41 м × 18 м)
- **Висота:** 4 м
- **Стелажів:** 19 одиниць
- **Зон:** 5 (Північна, Південна, Східна, Західна, Центральна)
- **Полиць:** від 4 до 6 на кожному стелажі
- **Входів:** 3 (головний південний, 2 бічних західних)

## 🔥 Актуальність

Підприємство спеціалізується на комплектуючих для причепів та тентів. Асортимент — понад 500 позицій: вісі, ресори, електрика, освітлення, фурнітура тощо. До впровадження системи комірники витрачали в середньому **8-12 хвилин** на пошук одного товару. З 3D-візуалізатором цей час скорочується до **2-3 хвилин** (включаючи фізичне переміщення).

## ✨ Функціонал

### 🔍 Навігація та пошук

|        Функція          |                                Опис                                  |          Технологія           |
|-------------------------|----------------------------------------------------------------------|-------------------------------|
| **3D-візуалізація**     | Повна модель складу з усіма стелажами, проходами, кімнатою персоналу | Three.js r128                 |
| **Пошук за текстом**    | Пошук за назвою, артикулом, категорією з автокомплітом               | REST API + debounce           |
| **Голосовий пошук**     | Розпізнавання української мови для рук вільного пошуку               | Web Speech API                |
| **Сканер штрихкодів**   | Читання EAN-13, Code 128, Code 39 через камеру                       | QuaggaJS                      |
| **Оптимальні маршрути** | Побудова шляху від найближчого входу до стелажа з часом              | Алгоритм A* (спрощений)       |

### 📦 Управління товарами

- **Додавання** — через форму або імпорт
- **Редагування кількості** — кнопки +/- з валідацією залишків
- **Переміщення** — між стелажами та полицями
- **Видалення** — з підтвердженням
- **Історія операцій** — хто, коли, що змінив (локально + на сервері)

### 👷 Система комірників

|          Роль         |                Права               | Ідентифікація |
|-----------------------|------------------------------------|---------------|
| **Старший комірник**  | Повний доступ, налаштування        | PIN-код       |
| **Комірник**          | Редагування кількості, переміщення | PIN-код       |
| **Тільки перегляд**   | Без змін                           | Без PIN       |

Особливості:
- авторизація зберігається в `localStorage` (сесія не втрачається при оновленні);
- усі операції прив'язуються до користувача;
- можливість швидкої зміни користувача.

### 🌐 Інтеграції з зовнішніми системами

#### 1С:Підприємство
- **COM-підключення** (Windows) — прямий доступ до бази 1С
- **Файл вивантаження** — імпорт XML/Excel з 1С
- **OData API** — веб-сервіси 1С для онлайн-синхронізації
- **Автооновлення** — за розкладом (5/15/30/60 хвилин)

#### Excel / Google Sheets
- **Google Sheets** — імпорт через публічний CSV експорт
- **Excel Online** — OneDrive shared links
- **Пряме посилання** — на .xlsx або .csv файл
- **Локальна мережа** — шляхи типу `\\server\share\file.xlsx`

#### Автооновлення з папки
- Відстеження папки на нові файли
- Маски файлів (`*.xlsx`, `goods_*.csv`)
- Дії після імпорту: зберегти / видалити / перемістити в `Imported/`
- Інтервал перевірки: 30 сек — 5 хвилин

### 📱 Технічні особливості

#### PWA (Progressive Web App)
- Встановлення на домашній екран смартфона
- Робота в повноекранному режимі
- Push-сповіщення (заготовка для майбутнього)

#### Офлайн-режим
- **Service Worker** кешує статику та API-відповіді
- **Background Sync** — відкладена синхронізація при відновленні зв'язку
- **IndexedDB / localStorage** — черга операцій для синхронізації
- Індикатор статусу мережі

## 🚀 Швидкий старт

### Вимоги
- Python 3.8+
- pip

### Встановлення та запуск

1. **Клонувати або розпакувати проєкт**
2. **Встановити залежності:**
        pip install -r requirements.txt
3. **Запустити сервер:**
        python app.py
4. **Відкрити в браузері:**
        http://127.0.0.1:5001

**Для роботи з 1С (Windows):** pip install pywin32
**Для генерації тестових даних:** python generate_data.py
